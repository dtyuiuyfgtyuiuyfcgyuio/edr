# EDR 1.3.2026.1020

本版本面向 Windows 10 2004 / Windows 11 x64，提供代理、本地 Web 控制台、离线安装器和可选测试签名驱动。源码与安装器以 GitHub 的 `v1.3.2026.1020` 标签为准；公开配置清除了运行凭据，上报、自动响应、真实响应通道及可选驱动默认关闭。

## 本版内容

- **传感器与审计可见性**：采集 Sysmon 4/16/255 的服务状态、配置变化与错误，Security 4719 的策略明细和 1104 的日志已满事件；新增 EDR-529–533。状态与配置事件不单独证明恶意性。
- **计划任务证据**：Security 4698/4702 保留审计主体及任务定义，复用 EDR-032/033；任务 XML 最多 32768 UTF-8 字节，默认脱敏。Operational 日志补充任务/动作开始、完成、失败信息；引擎 PID 和 RPC 客户端信息仅作为元数据。
- **系统防护**：包含 Defender ASR 1121/1122/1129、CFA 1123/1124/1127/1128 和 Sysmon 25 的原生事件支持。提供方 PID 不作为行为进程或处置目标，阻断/审核语义分别保留。
- **检测与交付可靠性**：修正 DoH 的完成阶段计数、进程身份、滑动窗口及容量索引；DNS 不再按内容与短时间窗口猜测重复查询。Reporter 健康心跳分别报告告警与事件通道的 HTTP 尝试、成功、失败、连续失败及最近时间，HTTP 成功和 spool ACK 分别观测。
- **控制台与工程质量**：修正 incident 页面旧请求覆盖新结果的竞态，改进规则 lint、Security/提权原生字段与 Sysmon 文件删除契约，以及 Syslog 健康统计。正式规则 526 条，采集器/检测器/解析器为 36/167/10。
- **构建与安装验证**：CMake 将正式规则及情报 fixture 配置到构建树，支持位于源码树外的测试目录；安装版 launcher 支持显式验证端口与 IPC readiness，避免占用其他程序的 8080，常规安装默认值保持不变。

Windows 日志频道、审计策略和功能开关必须已启用且可读取；安装器不会安装或重新配置 Sysmon、Defender 或审计策略。新增记录不自动启用真实处置。

## 安装与校验

从 [Release](https://github.com/dtyuiuyfgtyuiuyfcgyuio/edr/releases/tag/v1.3.2026.1020) 下载 `EDR-Setup-1.3.2026.1020-x64.exe`，用同页的 `.sha256` 或 `SHA256SUMS.txt` 核验。正常安装需要管理员权限，默认组件为 agent 和 console，内置 Node.js v24.18.0 x64 与 VC143 应用本地运行库。

控制台默认监听 `127.0.0.1:8080`。运行密钥在目标机器生成；通过开始菜单的管理员访问入口查看。修复保留配置和密钥，卸载保留历史数据。具体步骤见 [安装指南](../packaging/windows/INSTALL.txt)。

可选 `ALL` 驱动沿用 2026-10-18 的测试签名产物，默认不选中；该产物没有因本版用户态功能重新构建。随包 CER 仅含公开证书。安装器本身尚未做发布代码签名，也不会修改证书信任、Secure Boot 或测试签名设置。驱动加载需要目标测试虚拟机事先准备好相应环境。

源码副本排除运行日志、告警账本、工作区记忆、签名私钥和包含静态 TLS 私钥样例的单个 HTTPS 测试文件；该测试保留于本地工作区。因此本地与公开副本的控制台测试数量不同。源码历史保留已有公开 GitHub 提交，不导入本地施工历史。

管理员服务安装、SYSTEM 开机启动、真实日志生成、真实内核加载及 Driver Verifier 尚未验收。非特权文件生命周期测试和合成事件管道测试不代表这些运行场景；原生隔离恢复测试依其权限门禁决定运行或跳过。
